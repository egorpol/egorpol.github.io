This is the first of what I intend to be a running set of notes on tools and workflows from my research.

I have just released an update to a tool I built several months ago. Originally designed to parse Wikipedia and IMSLP in order to identify composers whose works are in the public domain within the EU, it now includes a number of substantial additions.

## New Features and Improvements

- **PublicDomainSheetMusicFinder.ipynb**: Code optimisation and refactoring for improved performance and readability.
- **imslp_extract.ipynb**: Newly added notebook to parse all available scores for a selected composer from the IMSLP database.
- **llm_parse.ipynb**: Experimental notebook for parsing, summarising, and answering questions about a selected composer based on their Wikipedia article. This notebook uses locally running large language models provided in LM Studio.

For those interested in exploring these updates, the project is available on my GitHub: [PublicDomainSheetMusicFinder](https://github.com/egorpol/eu-pd-composers).

*Update (October 2026): the tool was later rebuilt as the versioned dataset and browser eu-pd-composers; see [The Public Domain Sheet Music Finder, three years later]({% post_url 2026-10-28-public-domain-sheet-music-finder-revisited %}).*

Stay tuned for more updates!
