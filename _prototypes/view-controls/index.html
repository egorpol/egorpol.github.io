Pixel and plain view controls

Four ways to separate the site-view choice from the light/dark theme. Each header below is interactive. Pixel / Plain is used as the working name, but the labels can change independently of the control design.

Naming

Why “Pixel”?

It describes what visitors immediately see and connects naturally to “Too many pixels?”. “Patcher” is more exact but more specialised; “8-bit” is clear but describes only the ZX part; “Signal” has character but needs explanation.
