# View-control prototypes

Standalone design study for the site-skin and light/dark controls. This folder
starts with an underscore, so Jekyll does not publish it with the website.

Open `index.html` directly in a browser, or serve the repository root locally
and visit `/_prototypes/view-controls/`:

```bash
python3 -m http.server 8766
```

The controls are deliberately independent experiments. Changes made here do
not affect the production header.
